Listas Ordenadas

Atributo das Listas

  1. reserved - Indica que irá ter uma nova lista
  2. start - Indica por qual elemento deve começar a numeração start="10"
  3. type
    1. 'a' - Indica letras minúsculas
    2. 'A' - Indica Letras maiúsculas
    3. 'i' - Indica algarismos romanos minúsculos'
    4. 'I' - Indica algarismos romanos
    5. '1' - Indica números (padrão)
